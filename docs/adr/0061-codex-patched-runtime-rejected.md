# 改造版Desktop試験の不合格と公式版への復旧

日付: 2026-09-13。状態: 決定済み。

## 決定

公式ソース改造版のDesktop再起動観測は、不合格として終了する。
Keychain要求の連発をオーナーが報告し、公式の通常構成へ戻して再起動した後に停止を確認した。
改造版の再有効化・製品への導入は行わない。

要求項目と連発の全経路は未確定。オーナーによる許可・拒否の混在操作もあるため、
Keychain失敗件数を署名による自動拒否の証拠にしない。
アプリ内ツールにある独立した署名条件は、配布物のコードを読んで確認した。

オーナーが新たに承認した公式バイナリと通信中継の試作は、同じ目的の次の検証として扱う。
Steer、終了後の同一task再開、通常Desktop機能維持の受入条件は保持する。
この決定は改造版試験の観測完了であり、中継方式や製品全体の受入を意味しない。
