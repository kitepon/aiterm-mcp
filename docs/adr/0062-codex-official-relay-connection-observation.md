# 公式バイナリ中継のDesktop接続試験の受入

日付: 2026-09-13。状態: 決定済み。

## 決定

公式バイナリを維持する通信中継について、macOS Desktopの再起動観測を完了として受け入れる。
実行中の同じturnへのSteerと、正常終了後の同じtaskの自動再開を、実際の親で受信して確認した。
中継稼働中も公式App ServerがDesktopの直接の子であり、アプリ内ツールのtask読取りが成功した。

これにより、検証したmacOS構成ではApp Serverの再ビルド・署名変更をせずに、
目的の配送経路を設けられることが実証された。公式ソース改造版の再有効化は行わない。

この判定は接続試験についてのものである。Aitermの製品回答配送と選択導入、
Windows native・Linuxの実機確認は未完了として残す。通常製品のqueue配送はまだ変わっていない。
アプリ全機能を網羅した試験、入力の画面表示、Keychain要求の連発の全経路特定は、
今回の成功から推定しない。
