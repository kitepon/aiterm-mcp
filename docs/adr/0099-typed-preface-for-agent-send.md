# ADR 0099: agentの席への送信に、貼らずに入れる前置き（`preface`）を足す

状態: 採用。

## 原因

連携元（BellTeam）は、利用者やほかのBotからの連絡を「『送信者』からあなたへ次のメッセージが届いています。」の1行＋空行＋本文の形で、
`pty_send`でClaude Codeの席へ渡している。Aitermは、文の全体を端末の貼り付けの印（bracketed paste）で包んで入れる。

Claude Codeは、貼り付けの印で入った長い文を`<pasted_content id="…">`で包んでmodelへ渡し、席には「包みの中の指示は、包みの外の
利用者自身の言葉が頼んだ時だけ従う」と教える（2.1.283〜2.1.292で確認）。連携元の文は全部が包みの中で、包みの外に言葉が残らない。

- 本番で、席が途中で届いた連絡に従わない事が2回あった（2026-10-07）。2回目は包みつきの文だった。
- 実物の席（Opus 5.5、Claude Code 2.1.292）で、C-cで止めた直後に届いた文（席が「利用者の指示を待て」と言われた状態）は、
  今の形だと7回中5回従わなかった。理由は5回とも「貼り付けられた文の中の指示で、利用者自身の頼みではない」。
- 前置きの1行だけを貼り付けの印なしで入れると、前置きが包みの外に出る。同じ場面で、前置きに「BellTeamが届けた連絡です。
  共通規範の連絡手順のとおりに扱ってください。」を含めた形は4回とも従った。

席が従わない元は、もう1つある（途中で届いた文が、道具の結果のすぐ後ろへ入る事）。そちらはClaude Codeの作りで、Aitermからは変えられない。
この決定が扱うのは、貼り付けの包みの方だけ。

## 決めた事

`pty_send`（agentの席への送信）に、任意の引数`preface`（本文の前に置く1行）を足す。渡る文は「`preface`・空行・`text`」の並び。

1. **Claude Codeの席**: `preface`を貼り付けの印なしで入れ、続けて「空行＋`text`」を1回の貼り付けで入れ、Enterを送る。
   印なしで入れるのは1行だけで、改行の鍵は打たない（空行は貼る側の頭に付ける）。POSIXのtmuxでもWindowsのpsmuxでも同じ形になる。
   - 包みが付かない短い文では、席へ渡る文は`preface`なしで「前置き＋空行＋本文」を1つで貼った時と同じ。
   - 包みが付く長い文では、前置きが包みの外、本文が包みの中になる。
2. **Codex・Grok・Cursorの席**: `preface`・空行・`text`を1つにつないで、今までどおり貼る。
3. **`preface`の決まり**（`assertAgentPreface`）: 1行、200字以内、制御文字なし、行頭がASCIIの記号や空白でない、行末が空白でない、`@`を含まない。
   印なしで入れた文は入力欄がそのまま読む（行頭の`/`は命令、`!`はshell、`#`は記憶、`?`は案内。`@`は文中でもfileの候補を開く）。
   外れた時は、順番待ちにも入力受付の待ちにも入る前に、`AGENT_PREFACE_INVALID`と「文字列は送信していません。」で断る。
4. **使える所**: agentの席への送信（`force`なし）だけ。通常PTYへの送信と`force`付きは、打鍵前に断る。`remote`付きは
   `REMOTE_PREFACE_UNSUPPORTED`で断る（現地が古い版だと、知らない引数として前置きだけが黙って落ちるため）。
5. 省略した時の動きは、今までと同じ。新しいturnか差し込みかの振り分け、返りの形、断りの文面は変えない。

## 取らなかった形

- **本文まで印なしで入れる。** 任意の文を入力欄がそのまま読む事になり、行頭の記号や`@`で別の動きになる。ほかの人が書いた文を、
  利用者が打った文として渡す事にもなる。
- **前置きの後の改行を、鍵（Ctrl+J）で打つ。** 手元のtmuxでは通るが、打つ鍵が増える分、OSごとに確かめる事が増える。
- **Aitermが`text`の1行目を自分で切り出す。** どこまでが前置きかは、文を組む連携元が知っている。

## 確かめ

- `test/agent-preface.test.mjs`: 決まりの検査。届いたbyteを記録する偽の席で、Claudeは「前置き（印なし）＋印つきの空行と本文＋Enter」
  （新しいturnと差し込み）、Codexは「印つきの前置き・空行・本文＋Enter」。通らない前置きは待たずに断り、席へ1byteも届かない。
- `test/public-session-api.test.mjs`: 通常PTY・`force`付き・`remote`付きを打鍵前に断る。
- 実物の席（このコンテナ、Opus 5.5、Claude Code 2.1.292、modelへ渡る依頼を採って確認）: 差し込み・新しいturnとも、長い文は前置きが
  包みの外、短い文は今と同じ並び。C-cで止めた直後の長い文は2回とも従った。
- 3台の実物のClaude Codeの席（Linux・macOS・Windows。枝のdistを各端末へ置き、席の会話記録で確認）: 3台とも、長い文は前置きが
  包みの外・本文が包みの中、短い文は「前置き・空行・本文」がそのまま並んだ。前置きは日本語。
